# Formulário de Reporte de Bugs - ReTool

O script `retool/scripts/criarFormularioBugReTool.js` cria o formulário de reporte de bugs no Google Forms (via Google Apps Script).

Como usar: [Guia do Desenvolvedor → Scripts auxiliares](https://github.com/CAKeysama/ReTool/wiki/Guia-do-Desenvolvedor#scripts-auxiliares). O botão **"Encontrou algum bug?"** da Home abre o formulário publicado.
